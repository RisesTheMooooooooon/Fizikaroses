ФИЗИКА SK/RU — ПАКЕТ ДЛЯ САЙТА

Почему файл не работает в предпросмотре Telegram
------------------------------------------------
Telegram на iPhone отключает JavaScript у HTML-вложений. Поиск и фильтры нельзя заставить работать в этом локальном предпросмотре одной правкой HTML. Надёжное решение — опубликовать страницу как обычный HTTPS-сайт и отправлять в Telegram ссылку, а не сам HTML-файл.

БЫСТРАЯ ПУБЛИКАЦИЯ ЧЕРЕЗ GITHUB PAGES
-------------------------------------
1. На компьютере распакуй этот ZIP в отдельную папку.
2. На GitHub создай отдельный репозиторий, например fizika-sk-ru. Для бесплатного GitHub Pages он должен быть публичным.
3. Загрузи ФАЙЛЫ из этой папки в корень репозитория (именно сами файлы, не ZIP):
   - index.html
   - manifest.webmanifest
   - sw.js
   - .nojekyll
4. Открой Settings → Pages.
5. В разделе Build and deployment выбери Source: Deploy from a branch.
6. Выбери Branch: main и папку /(root), затем нажми Save.
7. Подожди публикации. GitHub покажет адрес сайта примерно такого вида:
   https://ТВОЙ-ЛОГИН.github.io/fizika-sk-ru/
8. Отправляй эту HTTPS-ссылку себе в Telegram сообщением. Не прикрепляй index.html как файл.

ОТКРЫТИЕ ССЫЛКИ В SAFARI
-------------------------
В Telegram на iPhone открой Settings → Privacy and Security → Open Links и выбери Safari/внешний браузер (названия могут немного отличаться в зависимости от версии Telegram). Также можно зажать палец на HTTPS-ссылке и выбрать открытие во внешнем браузере, если такой пункт доступен.

ВАЖНО
-----
Нельзя гарантированно переключить локальное HTML-вложение из предпросмотра Telegram в Safari изнутри самого файла: iOS и Telegram блокируют такой сценарий ради безопасности. Для работающего поиска используй опубликованную HTTPS-ссылку.

Сайт состоит из статических файлов; отдельный сервер или база данных не нужны. Публикуя его в интернете, имей в виду, что страница будет доступна всем, у кого есть ссылка (а на GitHub Pages публичность репозитория обычно обязательна для бесплатного плана).
